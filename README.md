# Robot Testbed POC

한국어 프롬프트로 계획, 구현, 검증, GitHub 변경 관리를 연습하는 실습용 프로젝트입니다.

## 현재 단계

저장소 초기 준비 단계입니다. 앱 구현과 실행 가능한 화면은 아직 없습니다.

## 예정된 기능

- 한국어 이슈 목록과 상태별 건수
- 제목, 담당자, 목표일, 우선순위, 상태 등록·수정·삭제
- 상태 필터, 브라우저 로컬 저장, 한글 CSV 내보내기
- 실제 사업 자료와 구분되는 가상 샘플 데이터

## 작업 방법

첫 커밋과 GitHub 연결을 완료한 뒤 이 폴더를 Codex 프로젝트로 열고 Worktree에서 개발합니다. 기본 브랜치는 `main`입니다. 기능 구현 후 실제 검증 결과를 기록하고 PR로 검토합니다.

## 기존 대시보드

기존 리스크 대시보드는 상위 폴더의 `risk-dashboard`에 별도로 보존되어 있으며 이 실습 저장소에 포함되지 않습니다.

## 출처

사용자가 이 대화에서 지정한 POC 요구사항과 폴더 분리 요청을 기준으로 작성했습니다. 실제 로봇 테스트베드 사업 현황을 나타내는 자료는 포함하지 않습니다.
