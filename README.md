# 로봇 테스트베드 이슈 관리 보드

index.html을 Microsoft Edge에서 열면 실행됩니다. 설치·서버·외부 API·인터넷 연결은 필요하지 않습니다.

## 사용 방법
1. 가상 샘플 이슈 5건을 확인합니다.
2. 이슈 등록에서 제목·담당자·목표일·우선순위·상태를 입력합니다.
3. 수정·삭제 버튼으로 관리합니다. 삭제는 확인창에서 취소할 수 있습니다.
4. 상태 필터는 목록에만 적용됩니다. 상단 건수는 전체 데이터 기준입니다.
5. CSV 내보내기는 현재 표시된 목록을 UTF-8 BOM 형식으로 저장합니다.

모바일에서는 표 안을 좌우로 스크롤하면 모든 열을 볼 수 있습니다.

## 저장 범위
같은 브라우저·프로필·파일 위치의 localStorage를 사용합니다. 새로고침 후 유지되는 것을 Edge에서 확인했습니다. 파일 이동·다른 브라우저·브라우저 데이터 삭제 후 유지나 공동 편집은 지원하지 않습니다.

저장 실패 시 경고하며 변경은 메모리에만 남을 수 있습니다. 창을 닫기 전에 CSV를 내보내세요. 손상된 저장 데이터는 자동 덮어쓰기하지 않습니다. 이때 편집은 임시 상태입니다. 전체 삭제 후 빈 목록은 유지됩니다.

CSV 복원은 지원하지 않습니다. 수식으로 해석될 수 있는 값은 탭을 붙여 텍스트로 내보냅니다.

## 파일 구성
- index.html, styles.css: 한국어 화면과 반응형 스타일
- app.js: 화면 조작, 저장, 다운로드
- issue-core.js: 입력·저장 데이터 검증과 CSV 생성
- sample-data.js: 가상 이슈 5건
- tests/browser-test.cjs: Playwright 기반 Edge 검증
- TEST_REPORT.md: 검증 결과와 미검증 범위

## 테스트 재실행
개발용 Node.js와 Playwright, Microsoft Edge가 있는 환경에서 `node tests/browser-test.cjs <결과 폴더>`를 실행합니다. 일반 사용에는 개발 도구가 필요 없습니다. 테스트는 격리된 브라우저 환경을 사용합니다.
